## 1. 问题、假设与可否定结果

研究问题：历史表现较强的美国行业组合，能否在随后月份相对12行业等权组合继续获得收益？这种表现是否对成本、因子暴露、市场状态和少数极端时期敏感？

经济假设：信息逐步扩散、投资者反应缓慢或资金流延续可能造成行业收益持续；拥挤、估值修正和市场快速反转可能使持续性失效。这些是待讨论的解释，单靠组合收益不能识别因果。

主比较拟定为：12行业、12–2信号、前三行业等权、每交易名义金额30bp成本下，策略相对同成本口径12行业等权基准的月度主动收益 `a_t = r_strategy,net,t - r_equal,net,t`。报告均值及不确定性；不以从多个版本中挑出的最大夏普作为主结果。零成本、10bp、50bp一并报告。

均值不稳定、置信区间很宽、成本后优势消失、主要由市场或Mom解释，都属于有效结论。正均值不自动等于经济上可实施或统计上已证实的优势。

## 4. 基准规则与信息时间

`r_i,t`表示行业i在月份t的简单总收益，小数单位。拟定：

`signal_i,t = product(1 + r_i,s, s=t-12,...,t-2) - 1`

这是11个月复合收益，跳过t-1，不是“最近12个月简单相加”。例如持有2000-01，用1999-01至1999-11排序，跳过1999-12；2000-01收益仅用来计算持仓后的盈亏。

月初按上一月结束时可用信息形成目标权重：前三各1/3，其余0，持有一个月，再调仓。不加杠杆、不卖空、不根据市场状态择时。排名同分拟按固定行业代码顺序处理，不借后续表现打破同分。

这是假设月度研究数据可用于边界调仓的学术时序约定，并不证明French文件在每个月初已经发布，更不证明真实成交可实现。

毛收益 `r_p,t = sum(w_i,t * r_i,t)`。基准为每月重新等权的12行业组合；市场参考为 `Mkt-RF + RF`，不能直接把Mkt-RF当总收益。市场参考作为研究序列，不施加虚构的行业调仓成本。

实现前必须人工核算连续两次调仓；开发检查须证明改动月份t及未来的收益不会改变t及以前的目标持仓。允许t-1收益改变t的漂移权重和换手，不能把它误判为信号泄漏。

## 5. 成本与指标（第6周前逐项讲解）

漂移权重：`pre_i,t = w_i,t-1 * (1+r_i,t-1) / (1+r_p,t-1)`，先不含费用对相对权重的二阶影响。实际记账方式需在冻结前确定并手算核对。

双边交易量口径 `D_t = sum(abs(w_i,t - pre_i,t))`。从行业A全部换成B时D=2；现金首次建仓时只统计买入行业名义金额，D=1。不得再乘2；如展示半换手，单列为D/2且不能用于重复收费。

成本情景 `c ∈ {0, 0.001, 0.003, 0.005}`，即每一元交易名义金额0、10、30、50bp。拟采用月初扣费、剩余净值获取当月收益的近似模型：`r_net,t = (1-c*D_t)*(1+r_p,t)-1`。D按扣费前净值的目标差计算，未精确求解费用导致的目标交易量变化；这是学术敏感性近似，不是严格成交仿真。第6周必须明确保留近似还是改用自融资计算，并在最终测试前冻结。策略与等权基准用相同约定、均含期初建仓成本。

报告全区间和各时间段的净值、几何年化收益 `product(1+r)^(12/n)-1`、月收益样本标准差乘sqrt(12)、夏普 `sqrt(12)*mean(r-RF)/std(r-RF)`、最大回撤、最差月份、年度收益及平均D。零波动时夏普记为未定义。主动收益算术均值乘12应标为“年化算术主动收益”，不能冒充几何年化收益之差。

最大回撤基于含起始净值1的累计净值与历史最高值；明确报负回撤还是损失幅度。费用不能直接从几何年化收益中减去。图表和表格保持同区间、同频率、同收益口径。

## 6. 风险、状态与失效（拟定，不提前学习全部）

风险回归以策略净收益减RF为因变量，依次使用CAPM、三因子、三因子加Mom。报告月度截距、暴露、样本量、置信区间，不把正截距称作已证明的alpha；SMB/HML/Mom本身为多空因子，不再次减RF。

不确定性方法暂拟Newey–West HAC标准误、月度滞后6阶，主动收益均值用仅含常数项的回归估计。第7周理解其目的和局限后确定，留出期前冻结；小状态样本的估计只作描述，不据其显著性调模型。

市场状态候选规则只用截至t-1的市场总收益：

- 高波动标记：过去12个月波动超过开发期滚动波动的75%分位数。阈值由开发期计算并固定，验证期检查，不在最终留出期重估。
- 趋势分类互斥：过去12个月累计市场收益<0且t-1收益>0为“恢复代理”；累计收益<0且t-1收益<=0为“下跌”；其他为“其余”。恢复代理只是机械定义，不等于已确认危机结束。
- 波动标记和趋势分类分别报告，可能重叠，不能将它们合成样本量相加。分类只用于解释，不改持仓；阈值及窗口仍待冻结。

每组报告月份数、主动收益、风险和不确定性。失效案例按固定选择方式展示：各评估区间最差3个净收益月份、最差主动收益月份及最大回撤区间（重叠照实注明）。检查行业贡献、行业集中度、市场反转和成本，保留无法解释的部分，不事后挑事件只讲故事。
