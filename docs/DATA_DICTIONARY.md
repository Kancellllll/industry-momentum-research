## 3. 标准化字段（设计，尚未生成）

| 标准字段 | 来源或计算 | 含义与单位 | 必查事项 |
| --- | --- | --- | --- |
| month | 原始YYYYMM | 月度Period，展示YYYY-MM | 唯一、递增、日历连续；不是公布日 |
| industry_code | 官方列名及定义表 | 固定行业标识 | 保留原名与映射；12个唯一值 |
| industry_return | IND12目标月度区块 | 行业简单总收益，小数 | 原始若为百分数则除100；不得预先减RF |
| mkt_excess | FF3 Mkt-RF | 市场超额收益，小数 | 不是总收益 |
| smb | FF3 SMB | 小市值减大市值因子，小数 | 多空因子，不再减RF |
| hml | FF3 HML | 高账面市值比减低账面市值比因子，小数 | 多空因子，不再减RF |
| rf | FF3 RF | 当月无风险利率，小数 | 月度值，不再除12 |
| mom | MOM Mom | 个股赢家减输家动量因子，小数 | 不等同于本研究行业只做多策略 |
| market_total | mkt_excess + rf | 市场总收益参考，小数 | 同月、同单位相加 |
| split | month映射 | warmup/development/validation/holdout | 不依收益大小变动 |
| batch_id | 下载登记 | 原始批次标识 | 每行可追溯至文件和哈希 |

收益例：原始百分数2.5规范化后为0.025；-99.99与-999若为缺失哨兵，须在除100前转换为缺失。具体出现位置及文件自身说明待读取；不能把Mom构造说明中的个股CRSP缺失代码直接当作所有输出文件的规范。
